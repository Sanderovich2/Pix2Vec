# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] - 2026-09-18

### Added
- Первый публичный релиз Pix2Vec.
- 6 профилей трассировки: color, photo, logo, logo_inv, detailed, sketch — с реальными параметрами движка vtracer.
- In-memory трассировка через `convert_raw_image_to_svg`: временные файлы не создаются.
- Изолированный воркер-процесс на каждый файл: сегфолт движка не рушит пакет.
- Флаги CLI: `--overwrite`, `--no-menu`, `--no-open`, `--version`.
- Итоговая таблица с размерами и временем, прогресс-бар, цветной вывод с автоотключением.
- Пакет тестов на stdlib unittest (14 тестов).
- GitHub Actions CI: тесты на Python 3.11–3.14 × ubuntu / windows / macos.

### Fixed
- Профили не влияли на движок: kwarg-вызовы биндинга vtracer 0.6.15 сегфолтят, параметры теперь передаются позиционно.
- Дробные `width`/`height` (например WEBP) ломали регэксп: отсутствовал `viewBox`, размер в сводке был 0x0. Теперь SVG нормализуется — целые размеры и `viewBox` всегда.
- Повторные запуски плодили копии `имя-1.svg`, `имя-2.svg`, … Теперь без `--overwrite` файл пропускается, с `--overwrite` — перезаписывается.
- В классической консоли Windows печатались сырые ANSI-коды: включается Virtual Terminal Processing, иначе цвета отключаются.
- ESC-последовательности попадали в пайпы: цвета включаются только в живой консоли.
- Проводник открывался при скриптовом запуске: только при интерактивном старте или без `--no-open`.
- Меню молча брало профиль по умолчанию при неверном вводе: теперь повторный запрос, выход по `q`/`0`.
